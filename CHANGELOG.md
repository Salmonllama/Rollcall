# Changelog

All notable changes to Rollcall are recorded here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and Rollcall uses [semantic versioning](https://semver.org/).

## Unreleased

### Added

- **Setup wizard, Entra connection & portal authentication (milestone M2):** guided first-run setup protected by `ROLLCALL_SETUP_TOKEN`, RSA 3072 certificate generation with AES-256-GCM envelope encryption (`EphemeralKeySet` in-memory loading), downloadable `.cer` + PowerShell Entra app registration script, live permission & directory-role validation, single-tenant Entra OIDC sign-in with PKCE and 8-hour/1-hour cookies, double-submit CSRF protection, invite-only portal roles (`Admin`, `Approver`, `Technician`, `Auditor`) enforced server-side, and **Admin › Team & Connections**.
- **Design system & brand assets (milestones M2 & M10):** full React 19 UI strictly consuming `docs/brand/tokens.css` (enforced by `web/scripts/lint-tokens.mjs`), self-hosted Atkinson Hyperlegible Next & Mono fonts, Light/Dark/System theme toggle, signature components (`ChangePreview`, `JobStepProgress`, `ApprovalBanner`, `DestructiveConfirmDialog`), dev component reference page (`/dev/components`), automated PWA icons + manifest, and `docs/brand/social-preview.png` (1280×640).
- **Workflow engine, approvals & tamper-evident audit log (milestone M3):** `IWorkflowStep` plan/execute architecture, frozen SHA-256 plan hashing, live drift detection (`NeedsReview`), four-eyes approvals with self-approval blocking, PostgreSQL `FOR UPDATE SKIP LOCKED` job queue with graceful worker lease release, retry-from-failed-step execution, and append-only SHA-256 hash-chained `audit_event` table protected by a PostgreSQL trigger.
- **Directory views & Dashboard (milestone M4):** live Microsoft Graph v1.0 directory client with `$select` enforcement, `Retry-After` handling, searchable/filterable **Users**, **User detail** (attributes, groups, licenses, MFA, CA, activity), **Groups**, **Licenses**, and operational **Dashboard**.
- **Cloud management & pooled Exchange Online runner (milestone M5):** single and bulk user attribute editing, Entra security/M365 group management via Graph `$batch`, Exchange Online distribution list & mailbox management via a pooled runner verifying pinned `ExchangeOnlineManagement` 3.10.1 SHA-256 tree hash (ADR 0002), license and per-service-plan editing, MFA method management, RAM-only single-view Temporary Access Pass (TAP) & temporary password flow (`410 Gone` on second view), and session revocation.
- **Role templates, onboarding, scheduling & Welcome Pack PDF (milestone M6):** live-validated versioned role templates, cloud onboarding with strict collision blocking (no invented usernames), two-phase scheduled start-date activation, and a zero-native-dependency Welcome Pack PDF generator with optional Rollcall branding toggle.
- **Offboarding, OneDrive handover & Restore (milestone M7):** safety-ordered offboarding (sign-in blocked → sessions revoked → mailbox converted to shared strictly *before* license removal → GAL hide/OOO/forwarding → timed OneDrive manager handover reversal → group & license removal) with typed UPN confirmation and one-click **Restore user** from recorded undo metadata.
- **Conditional Access management (milestone M8):** Admin-only CA policy inspection and user/group target editing strictly patching `conditions.users`, hard-blocked break-glass exclusion protection, policy-wide lockout checks, typed policy confirmation + mandatory approval, and timed temporary exclusions with automatic reversal.
- **Hybrid Active Directory agent (milestone M9):** outbound-only Windows service (`Rollcall.Agent`) running under a gMSA (`New-RollcallGmsa.ps1` + `install-agent.ps1`), single-use enrollment tokens, ECDSA P-256 DPAPI-protected keys with 5-minute signed JWTs, dual-layer `OuScopeGuard` enforcement, all 16 AD job types, automatic hybrid source-of-authority routing, and offline `WaitingForAgent` resume.
- **Operations, hardening & security (milestone M10):** guided zero-downtime RSA certificate rotation with 30-day expiry warning, streaming UTF-8 BOM CSV audit export, **Admin › Health** subsystem diagnostics, `install.sh admin-reset <upn>` and `install.sh rotate-master-key`, container `no-new-privileges:true` hardening, STRIDE threat model (`docs/security/threat-model.md`), and generated `docs/reference/permissions.md` with CI freshness verification.
- **Complete documentation set (milestone M11):** all 10 Day-1 deployment steps, 11 Admin guides, 9 Technician guides, Troubleshooting, Contributor guides, MkDocs Material configuration (`mkdocs.yml`), `dev.sh`, and v1.0.0 live-environment verification walkthrough (`docs/release/v1.0.0-walkthrough.md`).
- **Installer & foundations (milestones M0 & M1):** `.NET 10` solution, React/TypeScript SPA, `/healthz` and `/readyz`, `install/install.sh` (install, update with rollback, backup, restore, status, logs, uninstall), Compose + Caddy HTTPS stack, GPLv3 license/SPDX/DCO CI, and ADRs 0001 & 0002.
