# Managing licenses

Open **Licenses** in the sidebar to see every subscribed SKU in your tenant with **Assigned**, **Available**, and **Total** seat counts.

## Assigning or removing licenses on a user

1. Open the user's **Licenses** tab.
2. **Direct assignments** can be added, removed, or customized by toggling individual **Service plans** (for example disabling Viva Engage while keeping Exchange Online and Teams enabled).
3. **Group-inherited licenses** are labeled with the source group name so you never attempt to remove a group-based license directly from the user.
4. Click **Preview changes** to check seat availability and confirm before applying. If a user has no `usageLocation` set, Rollcall prompts to set it first so Microsoft Graph does not reject license assignment.
