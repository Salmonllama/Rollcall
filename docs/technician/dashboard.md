# Dashboard

The **Dashboard** is your home screen when you sign in to Rollcall. It shows:

- **Approvals waiting** — Requests awaiting review by an Approver or Admin.
- **Upcoming scheduled runs** — Scheduled onboardings, offboardings, or timed access reversals due soon.
- **Runs needing attention** — Partially failed runs (ready to retry) or runs paused by drift detection (`Needs attention`).
- **License seat alerts** — Microsoft 365 SKUs with low remaining seats.
- **AD agent status** — Live heartbeat health for enrolled hybrid Active Directory agents (when hybrid mode is enabled).
- **Recent runs** — Latest workflow activity with direct links to each run's step log.

Use the global search box in the top bar (or press `/`) from any page to jump straight to a user.
