# Finding users

Open **Users** in the sidebar (or type a name, UPN, or department in the top search bar) to search your Microsoft Entra ID directory.

## Filters

- **Search:** matches display name, UPN, mail, or job title.
- **Department:** filter to a specific department.
- **Account status:** show all users, enabled only, or blocked sign-in only.
- **Source:** filter between **Cloud** accounts and **Synced from AD** hybrid accounts.

## User detail tabs

Clicking any user opens their profile with tabs for:

- **Overview & attributes** — Contact, job, manager, and source-of-authority indicators (cloud vs. AD-synced).
- **Groups** — Security groups, Microsoft 365 groups, Teams, and Exchange distribution lists.
- **Licenses** — Direct and group-inherited SKUs with per-service-plan visibility.
- **MFA & sign-in** — Registered authentication methods, Temporary Access Pass (TAP), session revocation, and password reset.
- **Conditional Access** — Read-only view of which CA policies apply to or exclude this user.
- **Activity** — Every Rollcall workflow run targeting this user.
