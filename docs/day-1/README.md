# Day-1 deployment guide

This guide takes you from an empty Linux server to Rollcall running your first test onboarding. Work through the steps in order. Each step says what you're doing, gives the exact command or screen, shows the expected result, and ends with "Check it worked".

1. [Prerequisites checklist](01-prerequisites.md)
2. [Run the install command](02-install.md)
3. Create the Entra app registration *(arrives with the setup wizard)*
4. Assign directory roles *(arrives with the setup wizard)*
5. Sign in as the first admin *(arrives with the setup wizard)*
6. Hybrid only: install the AD agent *(arrives with the AD agent)*
7. Build the first role template *(arrives with role templates)*
8. Run a test onboarding and offboarding *(arrives with onboarding and offboarding)*
9. Set up and test backups *(see [Installer commands](../admin/installer-commands.md) for now)*
10. Go-live checklist *(arrives with v1.0)*
